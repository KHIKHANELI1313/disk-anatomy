# დისკების ანატომია

ინტერაქტიული გაკვეთილი შემნახველ მოწყობილობებზე: HDD, SATA SSD და NVMe SSD.

**საიტი:** https://disk-anatomy.netlify.app

- წარწერიანი ილუსტრაციები: HDD (შიგნიდან და ქვემოდან), 2.5" SATA SSD, M.2 2280 NVMe SSD, დედაპლატა
- წარწერაზე მაუსის მიტანისას იხსნება განმარტება (ტელეფონზე — შეხებით)
- შედარების ცხრილი, სიჩქარის დიაგრამები, TBW კალკულატორი
- პრაქტიკული დავალებები და 22 საკონტროლო კითხვა პასუხებით

საიტი ერთი ფაილია — `index.html`. ბილდი არ სჭირდება.
